# atlassian_jira_custom_field_option (Data Source)

Looks up a Jira custom field option by field, context and option ID, including cascading children. Requires Administer Jira.

## Example Usage

```terraform
data "atlassian_jira_custom_field_option" "example" {
  field_id   = "customfield_10000"
  context_id = "10100"
  id         = "10201"
}
```
