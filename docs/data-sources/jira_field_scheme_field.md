# atlassian_jira_field_scheme_field (Data Source)

Reads a field association and its issue-type restrictions from a Jira field scheme using the experimental API. Requires Administer Jira.

## Example Usage

```terraform
data "atlassian_jira_field_scheme_field" "existing" {
  scheme_id = "10000"
  field_id  = "customfield_10000"
}
```
