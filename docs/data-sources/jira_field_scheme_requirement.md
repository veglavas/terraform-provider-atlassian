# atlassian_jira_field_scheme_requirement (Data Source)

Reads the effective required flag for an existing field and issue type in a Jira field association scheme using the experimental Field schemes API. Falls back to the scheme default when no required override is returned. Does not describe native JSM request-form visibility.

## Example Usage

```terraform
data "atlassian_jira_field_scheme_requirement" "example" {
  scheme_id     = var.scheme_id
  field_id      = var.field_id
  issue_type_id = var.issue_type_id
}

output "is_required" {
  value = data.atlassian_jira_field_scheme_requirement.example.is_required
}
```
