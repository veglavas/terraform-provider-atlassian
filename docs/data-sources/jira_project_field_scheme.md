# atlassian_jira_project_field_scheme (Data Source)

Discovers the existing Jira field association scheme for a project using the experimental Field schemes API. Read-only; does not assign or create a scheme. A scheme may be shared by multiple projects. Requires Administer Jira permissions.

## Example Usage

```terraform
data "atlassian_jira_project_field_scheme" "example" {
  project_id = var.project_id
}

output "field_scheme_id" {
  value = data.atlassian_jira_project_field_scheme.example.id
}
```
