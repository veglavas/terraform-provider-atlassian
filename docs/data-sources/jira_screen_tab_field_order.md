# atlassian_jira_screen_tab_field_order (Data Source)

Use this data source to read the current field order of a Jira Cloud screen tab. It reads Jira and agent-side JSM Create/Edit screens only; it does not describe native JSM customer-portal request form layouts.

## Example Usage

```terraform
# Read the current field order of a screen tab (Jira and agent-side JSM
# Create/Edit screens; not the native JSM customer-portal request form).
data "atlassian_jira_screen_tab_field_order" "example" {
  screen_id = "10001"
  tab_id    = "20001"
}

# The remote order is exposed verbatim, first to last:
# data.atlassian_jira_screen_tab_field_order.example.field_ids
```

## Schema

### Required

- `screen_id` (String) The ID of the screen that owns the tab.
- `tab_id` (String) The ID of the screen tab.

### Read-Only

- `field_ids` (List of String) The field IDs on the tab, in the remote order from first to last.
