# atlassian_jsm_request_type (Data Source)

Reads a Jira Service Management request type by service desk ID and request type ID, including types hidden from portal browsing. Requires access to the service desk.

## Example Usage

```terraform
data "atlassian_jsm_request_type" "example" {
  service_desk_id = "2"
  id              = "10"
}
```

## Schema

### Required

- `id` (String) The request type ID.
- `service_desk_id` (String) The numeric service desk ID, not the Jira project ID or key.

### Read-Only

- `description` (String) The request type description.
- `group_ids` (Set of String) Observed portal group IDs. Empty means hidden from portal browsing.
- `help_text` (String) The request type help text.
- `issue_type_id` (String) The associated issue type ID.
- `name` (String) The request type name.
- `portal_id` (String) The customer portal ID.
