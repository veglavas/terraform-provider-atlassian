# atlassian_jsm_service_desk (Data Source)

Looks up the JSM service desk associated with a Jira project. Reference a managed service project's id to discover its service desk during apply, without manually supplying a service desk ID. Only desks visible to the authenticated user can be found. Retries absence for up to 30 seconds for newly provisioned service desks.

## Example Usage

```terraform
# Reference your existing Terraform-managed service project.
data "atlassian_jsm_service_desk" "example" {
  project_id = atlassian_jira_project.service.id
}

# Pass data.atlassian_jsm_service_desk.example.id to request types'
# service_desk_id. No manually discovered service desk ID is required.
```
