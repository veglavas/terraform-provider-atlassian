# atlassian_jira_custom_field_option (Resource)

Manages one option of a Jira custom field context, including cascading children. Other options are not managed. Requires Administer Jira. Prefer disabling options to deleting values used by existing issues. Ordering and app-owned options are not supported.

## Example Usage

```terraform
resource "atlassian_jira_custom_field_option" "parent" {
  field_id   = "customfield_10000"
  context_id = "10100"
  value      = "Department A"
}

# Omit parent_option_id for ordinary select fields and top-level options.
resource "atlassian_jira_custom_field_option" "child" {
  field_id         = atlassian_jira_custom_field_option.parent.field_id
  context_id       = atlassian_jira_custom_field_option.parent.context_id
  parent_option_id = atlassian_jira_custom_field_option.parent.id
  value            = "Unit A1"
  disabled         = false
}
```

## Schema

### Required

- `context_id` (String) The context ID. Changing this replaces the option.
- `field_id` (String) The custom field ID. Changing this replaces the option.
- `value` (String) The option's display value.

### Optional

- `disabled` (Boolean) Whether this option is disabled.
- `parent_option_id` (String) Parent option ID for a cascading child. Omit for a top-level option. Changing this replaces the option. Reference the parent resource ID to establish creation/deletion dependencies.

### Read-Only

- `id` (String) The option ID.
