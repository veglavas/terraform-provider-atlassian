# atlassian_jira_field_scheme (Resource)

Manages an importable Jira field association scheme using the experimental Field schemes API. Requires Administer Jira. Owns the scheme name and description, not its fields, requirements, or project assignments. Deleting an assigned or system scheme is rejected by Jira. Import existing schemes before managing them; shared schemes affect all assigned projects.

## Example Usage

```terraform
resource "atlassian_jira_field_scheme" "managed" {
  name        = "Example field scheme"
  description = "Managed by Terraform"

  lifecycle {
    prevent_destroy = true
  }
}
```
