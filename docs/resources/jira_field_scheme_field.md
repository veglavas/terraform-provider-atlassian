# atlassian_jira_field_scheme_field (Resource)

Manages one field association in a Jira field scheme using the experimental API. Requires Administer Jira. Owns the complete issue-type restriction set for this field in this scheme. Does not manage screen placement or native portal visibility. Removing an association also removes its scheme parameters and issue-type overrides; destroy requirement resources first. Import existing associations to avoid unintentionally changing restrictions.

## Example Usage

```terraform
resource "atlassian_jira_field_scheme_field" "managed" {
  scheme_id      = atlassian_jira_field_scheme.managed.id
  field_id       = "customfield_10000"
  issue_type_ids = ["10001", "10002"]
}
```

## Schema

### Required

- `field_id` (String) Jira field ID, such as customfield_10000.
- `scheme_id` (String) Field scheme ID.

### Optional

- `issue_type_ids` (Set of String) Complete set of issue types to which the field is restricted. Empty or omitted means all issue types; updating replaces the previous restriction set.

### Read-Only

- `id` (String) SCHEME_ID:FIELD_ID.
