# atlassian_jsm_request_type (Resource)

Manages a Jira Service Management request type in a company-managed (classic) service project. Requires service desk administrator permissions. Creation/deletion use documented experimental APIs. All configurable changes require replacement: no public update endpoint exists. Deletion removes this request type from existing customer requests. Use prevent_destroy for production request types. New request types are hidden from the portal until grouped manually; portal groups, forms, icons, and status mappings cannot be configured here.

## Example Usage

```terraform
# Reuse a managed service project; the lookup also works when the project is
# created in the same apply. See examples/jsm-request-types for a full setup.
data "atlassian_jsm_service_desk" "example" {
  project_id = atlassian_jira_project.service.id
}

resource "atlassian_jsm_request_type" "example" {
  service_desk_id = data.atlassian_jsm_service_desk.example.id
  issue_type_id   = atlassian_jira_issue_type.joiner.id
  name            = "Employee onboarding"
  description     = "Request onboarding for a new employee."
  help_text       = "Provide the details needed for HR validation."

  # All configurable changes require replacement. Deleting a request type
  # removes it from existing customer requests.
  lifecycle {
    prevent_destroy = true
  }
}

# Newly created request types are hidden from portal browsing until grouped
# in Jira. Portal grouping and form layout are not managed by this resource.
```

## Schema

### Required

- `issue_type_id` (String) The existing parent issue type ID to associate with this request type. Changing this replaces the request type.
- `name` (String) The request type name. Changing this replaces the request type.
- `service_desk_id` (String) The numeric service desk ID, not the Jira project ID or key. Changing this replaces the request type.

### Optional

- `description` (String) The request type description. Changing this replaces the request type.
- `help_text` (String) The request type help text. Changing this replaces the request type.

### Read-Only

- `group_ids` (Set of String) Observed portal group IDs. Read-only; configure grouping in Jira. Empty means the request type is hidden from portal browsing.
- `id` (String) The request type ID.
- `portal_id` (String) The customer portal ID.
